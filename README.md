# 🐱 Battle Cats Discord Bot

**基於 BCSFE 核心的貓咪大戰爭存檔管理 Discord 機器人**

## 專案簡介

本專案是一個專為《貓咪大戰爭》玩家設計的 Discord 機器人，透過直覺的按鈕面板操作，讓使用者無需輸入複雜指令，即可完成存檔的下載、修改、簽章與上傳。後端整合 BCSFE 核心引擎，封裝與 PONOS 官方伺服器的通訊協定，並同時提供 FastAPI 網頁服務。

本工具旨在提供便利的存檔編輯體驗，同時引入權限隔離、私人回覆與安全限額保護機制，最大程度降低存檔異常與帳號風險。

## 核心特色

### 按鈕式互動面板

* **無需指令**：所有功能透過 Discord 按鈕與彈出式輸入框完成。
* **多步驟編輯**：可先排入多項修改（貓糧、XP、解鎖貓咪等），最後一次上傳。
* **私人回覆**：所有引繼碼與操作結果僅使用者本人可見，避免敏感資訊外洩。
* **永久有效**：按鈕設有 `custom_id` 並於重啟後重新註冊，不會因逾時失效。

### 嚴格權限控管

* **單一擁有者**：只有指定的 Discord 使用者 ID 能操作面板，其他人點按鈕只會收到「無權使用」。
* **全流程保護**：從指令、按鈕、Modal 到子面板，每一層都有權限檢查。
* **公開面板、私密操作**：面板本身公開無妨，因為所有敏感回覆皆為 ephemeral。

### 全方位資源與進度編輯

* **基礎資源**：貓罐頭、經驗值 (XP)、NP、領導力、遊玩時間。
* **轉蛋券與材料**：銀券、金券、白金碎片、稀有券（安全模式）、傳說券、喵力達、貓眼石、貓薄荷、獸石、本能玉、城堡素材。
* **關卡與解鎖**：世界篇、未來篇、宇宙篇、魔界篇進度、批次貓咪型態解鎖與等級調整。
* **帳號管理**：解除封鎖、時間戳重設、清除封號旗標。

### 安全帳號移植與身分隔離

* **無損進度移植**：支援將來源存檔的貓咪解鎖、金寶進度、關卡紀錄與資源完整轉移至目標帳號。
* **詢問碼身分隔離**：自動沿用目標空殼帳號的詢問碼與伺服器憑證，防止因多存檔共用相同識別碼而引發連帶封鎖。
* **時間戳重設與自動註冊**：上傳前清洗異常時間戳記並清除封號旗標。

### 高安全性數值管理 (Dirty Check)

* **增量比對上傳**：僅上傳使用者實際修改過的欄位，減少對未變更記憶體區塊的動態覆寫。
* **嚴格安全上限**：針對貓罐頭、經驗值、各類票券設定安全防護閾值（例如貓罐頭上限 45,000），避免觸發伺服器自動封禁機制。

## 運作原理

本工具後端透過 `ServerHandler` 封裝與 PONOS 官方伺服器通訊協定。使用者輸入引繼碼登入後，伺服器會將存檔下載至記憶體中解析為 `SaveFile` 物件。前端透過 RESTful API 進行數值修改與增量比對，確認後重新簽章並上傳至 PONOS 伺服器，回傳全新引繼碼與認證碼。

Discord 機器人則以 `discord.ui.View` 實作互動面板，將上述流程包裝成按鈕操作，底層呼叫相同的 BCSFE 核心引擎。

## 指令列表

| 指令 | 功能 |
|------|------|
| `!panel` | 開啟主面板（修改存檔用） |
| `!newpanel` | 開啟空殼帳號面板 |

├── 🐱 貓咪操作 → 解鎖全部、全型態、等級全滿
├── 🔓 帳號管理 → 解除封鎖、時間戳重設、清除封號旗標
└── 📤 上傳並取得新碼

```

## 快速開始

### 環境需求

* Python 3.9+
* Discord Bot Token

### 安裝

```bash
pip install -r requirements.txt
```

設定

```bash
# Windows
set DISCORD_TOKEN=你的_TOKEN

# Linux / Mac
export DISCORD_TOKEN=你的_TOKEN
```

啟動

```bash
python main.py
```

啟動後：

· 網頁服務：http://localhost:8000
· Discord 面板：在頻道輸入 !panel

存檔修改流程

1. 於遊戲內進入「選單」→「轉移引繼資料」。
2. 點擊「上傳存檔到伺服器」，記下引繼碼與認證碼。
3. 於 Discord 輸入 !panel，點「🔑 輸入引繼碼」填入資料。
4. 點選要修改的項目（可累積多項）。
5. 點「📤 上傳並取得新碼」，取得全新引繼碼。
6. 於遊戲中選擇「恢復引繼資料」並輸入新代碼即可完成載入。

專案結構

```
battlecats-bot/
├── main.py              # 唯一入口（FastAPI + Discord Bot）
└── requirements.txt     # 依賴套件
```

注意事項

· 引繼碼只能用一次：每次上傳後舊碼失效，需使用新的。
· 貓糧上限 45,000：超過 48,000 有被封鎖風險。
· 解 Ban 需 Root 環境：被封鎖的帳號無法透過遊戲內轉移系統上傳，需 root 權限的裝置或模擬器。
· Token 請妥善保管：勿上傳至公開平台。

· 請支持正版遊戲《貓咪大戰爭》。
